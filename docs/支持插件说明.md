# dsh-git-idea 支持插件说明

> 写给想知道「本插件调用了 / 兼容了哪些其他插件」的人。规范要求：当前插件使用
> 其他插件时，要在这里写清楚支持哪些插件的版本、怎么关联、以及对应插件不存在
> 时会怎样。

## 结论

**本插件不调用任何其他插件的数据或服务** —— 面板与跨插件暴露 API 的全部数据都
来自本插件自己跑的 `git` 命令。对其他插件只有两处**可选的单向兼容**（都是对方
不在场就安静关闭），见下两节；没有任何功能因为缺哪个插件而失败。

## 可选兼容：DSH-better-sidebar（文件保存事件）

- **是什么**：DSH-better-sidebar ≥ 0.27.0 在内置编辑器保存文件成功后 emit cordis
  事件 `better-sidebar/file-saved`；本插件宿主半订阅它，命中已知仓库就失效读缓存
  并防抖广播刷新 —— 保存后约 1.5 秒面板自动跟着变。
- **怎么关联**：`src/host/79b-file-save.js` 用 `ctx.on('better-sidebar/file-saved', …)`
  订阅 cordis 事件。**不声明 `inject`**（否则对方未安装时本插件整个被停等），订阅
  是被动的：没人 emit，listener 永不触发。
- **降级行为**：未安装 / 版本过旧（不 emit）/ bridge 构建 / 路径不属于已知仓库 /
  没有浏览器连接 —— 五种情形全是 silent no-op，零报错，其余功能照旧。
- **详细契约**（payload 形状、链路、边界、手动验证）：见
  [联动插件.md](./联动插件.md)。

## 可选兼容：dsh-ssh-workspace（远程工作区）

- **是什么**：dsh-ssh-workspace 插件把一台 SSH 主机的目录挂成 DSH 工作区
  （`ssh://<别名>/<远端绝对路径>` 拼法）。本插件的面板要能读这种远程工作区里
  的仓库，就需要借它的 SSH 引擎开命令通道。
- **怎么关联**：本插件**不 import 它、不声明依赖**。dsh-ssh-workspace 接管
  `ctx.shell` 时在 shell 对象上留了一个标记
  （`Symbol.for('dsh-ssh-workspace.shell-installed')`，跨模块同键），挂着一个
  RemoteShellRouter；本插件只在会话工作区是 `ssh://` 拼法时才去读这个键
  （src/host/11-remote.js）。
- **能力协商**：拿不到 router（插件没装 / 没接管 shell）→ 一切按本地仓库处理；
  拿到 router 但引擎没有 `openChannel()`（老版本的 ssh 插件）→ 只对 cmd 方言的
  主机退回 shell 层老路，并记一条 console.error，之后不再刷屏。
- **降级行为**：ssh 插件不在场时，`ssh://…` 的仓库在本插件所有读（包括本说明
  之上的跨插件 summary / log API）里表现为「这一仓读不动」，答复行带
  `ok:false` 与原因；本地仓库完全不受影响。没有任何功能因为缺它而失败。
- **版本**：无硬性版本要求；`openChannel()` 形态是 Git Bash 通道（Windows 主机
  cmd 方言）的推荐形态，POSIX 远端走 shell 层透传即可。

## DSH 本体服务（不是插件，但一并说明）

本插件依赖并守卫这些 DSH 本体服务，缺哪个就静默少一块功能：

| 服务 | 用途 | 缺失时 |
| --- | --- | --- |
| `shell` | 跑一切 git 命令（唯一硬依赖，插件声明 `inject: ['shell']`） | 插件不注册任何 RPC / 路由 / 服务 |
| `webServer` | 面板静态资源外的 HTTP：RPC、ws、client-log、跨插件三条路由 | 面板退化、HTTP 通道不挂载，cordis 服务照常 |
| `sessions` / `sessionPersistence` | 会话工作区定位 | 按路径点名的调用不受影响 |
| `sandboxPolicy` | 读命令按会话沙箱执行 | 命令按部署默认策略执行 |
| `connection` | 本插件当前未使用 | - |

## 被扩展入口（本插件作为「被调用方」）

本插件对外暴露两条只读数据通道（cordis 服务 `dsh-git-idea` 与 HTTP
`/api/dsh-git-idea/*`），那是别的插件调用**本插件**，不属于本节范围 —— 详见
[被扩展说明.md](./被扩展说明.md)。
